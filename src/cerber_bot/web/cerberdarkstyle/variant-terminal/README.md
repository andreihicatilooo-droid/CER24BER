# Variant Terminal

Безопасный terminal-noir концепт для бренда «Ровное движение».

Что внутри:

- `index.html` — визитка с плиточным меню и секцией актуальных контактов.
- `register.html` — обновлённая форма доступа с alias, handle, городом и режимом связи.
- `join.html` — роли и условия работы в терминальной подаче.
- `chat.html` — mock внутреннего support-room после регистрации с правой колонкой контактов.
- `assets/styles.css` — phosphor/CRT визуальный язык с терминальными окнами.
- `assets/app.js` — переключение потоков в демо-чате.

Концепт намеренно статический и безопасный: без реальной синхронизации, без реальных интеграций и без серверной логики.
