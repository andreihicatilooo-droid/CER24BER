# Underground HTML Lab

Этот каталог нужен как изолированный стенд для проектирования визуального языка сайта без React, Next.js и BFF-логики.

Что внутри:

- `index.html` — аналог главной витрины и каталога.
- `preorder.html` — аналог страницы предзаказа.
- `auth.html` — аналог входа/стартового экрана.
- `assets/styles.css` — общие дизайн-токены, бетонный фон, карточки, кнопки, формы, модалки и сигнальный дождь.
- `assets/app.js` — минимальная интерактивность для демо: переключение фосфорного и натриевого режима, активные фильтры, модалки.
- `variant-yard/` — новый safe urban-концепт для бренда «Ровное движение»: визитка, регистрация, команда и внутренний чат.
- `variant-terminal/` — новый safe terminal-noir концепт с той же IA, но более жёсткой системной подачей.

Как использовать:

1. Откройте любой HTML-файл прямо в браузере.
2. Сравните базовый стенд и два новых варианта по стилю, IA и подаче форм.
3. После утверждения переносите блоки в текущие компоненты React.

Новые варианты собраны как безопасные статические концепты: без реальных интеграций, без внешней синхронизации и без серверной логики.

Куда переносить в проект:

- Шапка, фон, навигация: `src/components/layout/MainLayout.tsx`
- Главная витрина: `src/app/(shop)/page.tsx`
- Предзаказ: `src/app/(shop)/preorder/page.tsx`
- Общая тема и токены: `src/app/globals.css`
- Базовые кнопки/поверхности: `src/components/ui/*`

Рекомендуемый порядок внедрения:

1. Сначала перенести цветовые переменные, surface/button-стили и фоновые эффекты в `globals.css`.
2. Затем перенести header, hero, карточки и статусные лейблы в соответствующие React-компоненты.
3. В конце уже стыковать интерактивность и сигнальные слои с реальными данными и API.
