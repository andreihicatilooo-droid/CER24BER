Ритм очереди

  • 1. Выбор района и позиции Один алиас — один активный заказ. Без исключений. Без торга.
  • 2. Фиксация слота и оплаты Оплата подтверждает место в очереди. Отмена невозможна после списания.
  • 3. Ответ оператора Оператор выходит на связь в чате. Вопросы вне чата игнорируются.

Статус операторов

Холодные метки. Никакого маркетинга. Только актуальная информация по сети.

Время ответа

8–15 минут. Если оператор молчит дольше — ждёшь. Так устроен этот канал.

Режим связи

Только через чат покупки. Других каналов нет. Анонимность — это условие, не опция.

Протокол

Без объяснений, без извинений. Либо маршрут работает, либо возврат без лишних слов.

Города и позиции

Только активные узлы. Закрытые районы не отображаются. Что видишь — то доступно.

Правила очереди

Очередь — это не магазин. Это тоннель. Ты входишь, платишь, ждёшь, получаешь.

  • Один алиас — один активный слот в очереди.
  • Отмена после оплаты невозможна. Деньги замораживаются.
  • Оператор не обязан объяснять задержки. Это условие сети.
Молчание — норма

Отсутствие ответа не означает проблему. Оператор выйдет на связь когда посчитает нужным.
