ровное движение / город без лишних лиц

Тёмная визитка для бренда, который живёт между мокрым асфальтом, ником вместо биографии и коротким рабочим маршрутом.

Это безопасный стенд под мрачный underground-язык: без глянца, без дружелюбной витрины, с акцентом на анонимный ритм, контакты, вход и внутреннюю поддержку. Здесь важно не шоу, а ощущение закрытого городского узла.
