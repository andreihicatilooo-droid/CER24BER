# Variant Yard

Безопасный urban-концепт для бренда «Ровное движение».

Что внутри:

- `index.html` — визитка с плиточным меню и блоком актуальных контактов.
- `register.html` — обновлённая форма alias/контакта/города вместо простого логина.
- `join.html` — отдельная страница команды и условий работы.
- `chat.html` — внутренний support-chat после регистрации с контактами администраторов.
- `assets/styles.css` — бетонный визуальный язык: влажный асфальт, натриевый свет, тяжёлые панели.
- `assets/app.js` — переключение потоков внутри демо-чата.

Сценарий безопасный и статический: это только дизайн-лаборатория без реальной синхронизации чатов и без внешней логики.
